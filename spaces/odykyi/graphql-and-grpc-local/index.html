GraphQL and gRPC in local dev

Run GraphQL gateways and gRPC services locally, generate clients, inspect calls and connect them to a frontend.

  1. How to call a gRPC service from a browser: gRPC-Web and ConnectA browser cannot open a raw gRPC connection. You need a protocol it can speak: gRPC-Web through a proxy, or a server that understands Connect.
    3 min
  2. How to generate gRPC and Protobuf code with buf locallyprotoc works, but its flags grow fast. buf keeps the plugins, inputs and output paths in two small files you can commit and run the same way everywhere.
    3 min
  3. GraphQL Codegen in watch mode: typed queries while you codeTyped queries only help while they match the schema. Watch mode regenerates them on every save, so TypeScript flags a bad field before the browser does.
    3 min
  4. GraphQL CORS and CSRF errors from a local frontend: how to fixThe query works in curl but the browser refuses it. That is almost always CORS or CSRF prevention, and both are fixed on the server or with a dev proxy.
    4 min
  5. How to run GraphQL federation locally: subgraphs and a routerFederation splits one GraphQL schema across services. Locally that means several processes, one composed schema file and a router, all started in the right order.
    4 min
  6. How to test GraphQL subscriptions locally: SSE and WebSocketA subscription is a query that keeps the connection open. Test it from the terminal first, then from the browser, and fix the proxy that eats it.
    3 min
  7. How to add a gRPC health check so a local stack waits for itA gRPC server has no /health URL. You need another way to say 'ready', or the service that calls it will start too early and fail.
    3 min
  8. How to let gRPC services find each other in local developmentgRPC clients dial host:port, nothing more. Locally, the whole problem is choosing ports, passing addresses and starting servers before their callers.
    3 min
  9. How to run a GraphQL server locally and query it with curlA GraphQL API is one HTTP endpoint. Once you can hit it with curl, every other tool (a frontend, a codegen step, a test) is easy to wire up.
    4 min

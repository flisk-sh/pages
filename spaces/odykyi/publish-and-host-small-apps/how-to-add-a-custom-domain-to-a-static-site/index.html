How to add a custom domain to a static site

Point a domain you own at a static host: subdomain or apex, the DNS records involved, HTTPS, and the mistakes that cause a certificate error.

Add the domain in your host's settings, then create the DNS record it asks for: a CNAME for a subdomain like www, or the host's recommended records for the bare domain. Wait for DNS to propagate and HTTPS will be issued by the host.

Subdomain first

A subdomain such as docs.example.com is the easy case. Create a CNAME record pointing to the host's target, for example USER.github.io for GitHub Pages or my-site.pages.dev for Cloudflare Pages.

docs   CNAME   my-site.pages.dev

Then add docs.example.com in the host's custom domain settings so it knows to serve your site for that name.

The bare (apex) domain

A CNAME is not allowed at the apex by the DNS standard. Hosts handle this in one of three ways: they give you fixed A and AAAA records, they support a CNAME-like record such as ALIAS or ANAME, or your DNS provider flattens CNAMEs. Use the exact records from your host's docs. Do not copy IP addresses from a blog post, as they can change.

Check it with dig

dig +short docs.example.com CNAME
dig +short example.com A

If the answer is empty or old, DNS has not propagated or the record is on the wrong zone. Changes usually appear within minutes, but caching can stretch it longer.

HTTPS

Hosts issue a certificate automatically once DNS points at them. If you see a certificate error:

  • Check that no old A or AAAA record is still pointing elsewhere.
  • Check for a CAA record that blocks the host's certificate authority.
  • If a proxy such as Cloudflare's orange cloud is on, make sure the SSL mode matches what the origin supports.

A short checklist

  1. Buy or choose the domain and open its DNS settings.
  2. Add the domain in the host's dashboard first, so it tells you the exact records.
  3. Create those records and remove conflicting old ones.
  4. Wait for the host to show the domain as verified.
  5. Open the site over HTTPS and check that the redirect from the other name works.

Keep a note of every record you add. When something breaks a year later, that list saves an hour.

Redirect www to one name

Choose either example.com or www.example.com as the main address and redirect the other to it. Two live copies of a site split search ranking and confuse analytics. Most hosts have a setting for this redirect.

Once the domain works, make sure you are not publishing something you should not under your own name.

Questions people ask

How long does a domain take to start working?

Often minutes, sometimes up to a day because of DNS caching. The host's dashboard usually shows when the check passes.

Do I need to buy the domain from my host?

No. You can buy it from any registrar and point its DNS at the host.

Try it

Put one page online in a minute.

Pages publishes an HTML or Markdown file to a free public link. It is public, so do not use it for anything private.

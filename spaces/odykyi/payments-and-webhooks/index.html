Payments and webhooks locally

Test payment flows, webhook signatures, retries and idempotency on your laptop before anything touches production.

flisk-sh/flisk
  1. How to add idempotency keys to a payment API endpointA client that times out will retry, and a customer who is impatient will click twice. An idempotency key turns both into the same single charge.
    4 min
  2. How to handle out-of-order payment webhook eventsThe event that says a payment succeeded can arrive before the event that says it was created. Your handler has to give the same result either way.
    4 min
  3. How to reconcile payments after missed webhooksWebhooks are a fast path, not a guarantee. A job that asks the provider what really happened is the safety net, and it is easy to test by turning the receiver off.
    4 min
  4. How to build webhook delivery with signatures and retriesReceiving webhooks gets all the attention. If your product sends them, the hard parts are the retries you control and the signature your customers will verify.
    4 min
  5. How to run stripe-mock for offline payment testsSometimes you want to know that your code builds a valid Stripe request, not that Stripe charges a card. A local fake answers that in milliseconds.
    3 min
  6. Stripe test cards for declines, 3D Secure and insufficient fundsA payment flow that only ever sees 4242 4242 4242 4242 is untested. These are the cards that make Stripe fail on purpose, and what your code should do with each.
    3 min
  7. How to test subscription renewals with Stripe test clocksBilling code runs on the calendar. A test clock gives it a calendar you control, and Stripe sends the same webhooks it would in a month.
    3 min
  8. How to test refunds and chargebacks in Stripe test modeMoney going back out is where order, ledger and email logic disagree. Stripe test mode can produce every one of these events on demand.
    3 min
  9. How to test Stripe payments locally in test modeYou do not need a public URL or a live account to test a payment end to end. You need test keys, one forwarding command and an endpoint that checks signatures.
    4 min
  10. Webhook signature verification fails: use the raw request bodyThe signature covers the exact bytes the provider sent. Once a framework has parsed and re-serialized them, no key can make the check pass.
    3 min

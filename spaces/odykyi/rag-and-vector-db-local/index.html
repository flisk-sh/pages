RAG and vector databases locally

pgvector, Qdrant, Chroma and friends on a laptop: ingest documents, test retrieval and keep embeddings across restarts.

  1. Chroma vs Qdrant vs pgvector for a local RAG prototypeAll three store vectors and return nearest neighbours. They differ in what else they give you, and in how much of your prototype you must rewrite when you move on.
    3 min
  2. How to chunk documents for RAG: size, overlap and splittersChunking decides what the retriever can find. Most weak RAG answers come from chunks that cut an idea in half or bury it in unrelated text.
    3 min
  3. How to generate embeddings locally with Ollama, no API keyA local embedding model costs nothing per call, works offline and keeps your documents on your machine. Setting it up takes one container and one pull.
    3 min
  4. How to ingest documents into a vector database, repeatablyIngestion is a build step. If you can run it twice and get the same index, you can change chunking or models without fear.
    3 min
  5. How to keep vector database data between restartsRe-embedding a large corpus can take hours. Put the vector store on a named volume, and know exactly which command deletes it.
    3 min
  6. How to re-embed documents after changing the embedding modelA new embedding model means a new index. Done in the wrong order you get silently bad search, so build beside the old one and switch when it is proven.
    3 min
  7. How to run a full RAG stack on your laptop with DockerA RAG app is a few small services: a vector store, an embedding model, an ingestion job and an API. Here is how to start them together and check each one.
    3 min
  8. How to run pgvector locally with Docker for vector searchIf your app already uses Postgres, pgvector lets you store embeddings next to the rest of your data. Here is the smallest setup that works and keeps its data.
    3 min
  9. How to run Qdrant locally for development and RAG testsQdrant is a single container with a REST API and a web dashboard. Five curl commands are enough to know it works, and one volume keeps your data.
    3 min
  10. How to test RAG retrieval quality with a small eval setYou do not need a benchmark suite. Thirty real questions with known answers will tell you whether a change helped.
    3 min

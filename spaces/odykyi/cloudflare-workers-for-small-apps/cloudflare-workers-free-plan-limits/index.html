Cloudflare Workers for small apps

Cloudflare Workers free plan limits explained

What the free plan caps, how to read the limits, and the habits that keep a small app inside them, plus what changes when you outgrow it.

The free plan caps daily requests and CPU time per request. Roughly 100,000 requests a day and short CPU time per invocation were the figures at last check, but limits change, so read the official limits page before you rely on any number.

What is limited

  • Requests per day: once exceeded, further requests fail until the counter resets.
  • CPU time per request: this is compute time, not wall-clock. Waiting on a fetch or database does not count the same way.
  • Memory and subrequests: a request has caps on memory and on outbound calls.
  • Storage: D1, KV and R2 each have their own free allowances.
  • Script size: the bundled Worker has a size limit.

Read your usage

The dashboard shows requests, errors and CPU time per Worker. Look at it weekly in the first month. Stream live logs while testing.

npx wrangler tail my-worker

Stay inside the limits

  • Serve static files as assets or from a static host, not through your Worker code on every hit. See hosting small apps.
  • Cache with the Cache API or KV to avoid repeated work.
  • Ignore bot traffic early: return a cheap 404 for paths you do not serve.
  • Avoid heavy parsing or crypto in the request path.

Bots can eat your quota

Crawlers and AI scrapers hit public endpoints. A small site with a cheap handler can still burn through a daily cap. Add a robots.txt, block abusive paths, and put rate limiting in front of anything expensive.

Build a tiny request budget

Divide your daily request cap by the number of users you expect. If you have 100 daily users and a 100,000 request budget, each user can make 1,000 requests before you hit the wall, which is plenty for a form but not for a page that polls every second. Avoid polling. Use longer cache headers, batch calls from the client, and debounce search boxes. Count what each page load costs in Worker requests, including images if they pass through the Worker.

When you outgrow free

The paid plan raises request and CPU limits and adds features. Decide before you hit the wall: set an alert on usage, and have a plan for what happens when requests start failing. If a hobby app has no budget, a free-tier service such as the Host guide from Flisk may suit non-critical apps, with the usual caveats for early free hosting.

Questions people ask

What happens when I hit the daily limit?

Requests beyond the limit return an error until the counter resets. Check the limits page for the exact behaviour and reset time.

Does serving static files cost requests?

Depending on your setup, static assets may be free or counted differently. Check Cloudflare's current pricing for static assets.

Exercises

ExerciseDeliverable
1First run. Run npx @flisk-sh/flisk demo twice, then once with Docker stopped.LOG.md, heading # Lab 1: three timings and three points of friction.
2Build. flisk project agent-stack, then cd flisk-agent-stack && rm -rf .git && git init so the work is your own history. Add flisk resource my-api --type backend --stack agents --yes, then flisk up.Healthy flisk status --json under # Lab 2. README linking flisk.sh and the Flisk repository. No hand-written container files. Push to your new public repository.
3Diagnose. Introduce three faults. Find each with flisk doctor, flisk config verify or flisk logs.Table under # Lab 3: fault, symptom, command, fix, minutes. Three rows.
4Contribute. Open a pull request to flisk-sh/flisk. Write at least one test of your own for it.PR link under # Lab 4. GTM.md with three numbered answers: first 100 users, three integrations, one step this week.

Commit with git commit -s. Do not commit .env, node_modules or generated Flisk files (the starter's .gitignore already excludes them). Star the Flisk repository. Using an AI assistant is allowed; record what really happened.

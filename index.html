The 4 labs

1. Demo — run npx @flisk-sh/flisk demo twice, then with Docker off

Write 3 timings and 3 confusions under # Lab 1 in LOG.md.

2. Build — flisk project agent-stack, add one resource, flisk up

Add flisk resource my-api --type backend. Paste the healthy flisk status --json under # Lab 2. README links to flisk.sh and the Flisk repo. Do not hand-write container files.

3. Break it — 3 faults, found with flisk doctor, config verify or logs

Under # Lab 3, a table: fault | symptom | command | fix | minutes (3 rows).

4. Improve Flisk — open a pull request to flisk-sh/flisk, with a test

Put the PR link under # Lab 4. Add a test file to your repo. Then write GTM.md: 1. how to get the first 100 users, 2. three tools to integrate first, 3. one step this week.

You are scored on these 10 (10 points each)

  1. README links flisk.sh and the Flisk repo
  2. LOG.md has Lab 1 to 4
  3. Lab 3 table has 3 rows
  4. 3+ service.json files
  5. No .env or .flisk/ committed
  6. A test file
  7. Commits signed off (git commit -s)
  8. You starred flisk-sh/flisk
  9. PR open to flisk-sh/flisk
  10. GTM.md has 1. 2. 3.

  2. How much RAM do you need to run a local LLM?A model that does not fit in memory swaps or fails to load. You can estimate the fit with arithmetic before you download anything.

  3. How to keep Ollama models when the container restartsA model is a file of several gigabytes. If it lives in the container's own filesystem, every recreate throws it away. One volume fixes that.

    3 min
  6. How to use a GPU with Ollama in Docker (NVIDIA, Mac, WSL2)Where the GPU is available to a container depends on your operating system. Check this before you spend an hour on flags.
    3 min

  8. How to point the OpenAI SDK at a local Ollama serverMost LLM code already uses an OpenAI client. You can keep it and change two settings to run against a model on your own machine.
    3 min

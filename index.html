Two small files. flisk up. A whole stack.

Each part of the app is one short service.json. Press flisk up and watch Flisk write the rest, start a local gateway and Postgres, route requests, and rebuild only the part you save. Edit the ports below first if you like.

services/shop/orders-api/service.json backend

{
  "appName": "orders-api",
  "appType": "backend",
  "stack": "shop",
  "port": 4000,
  "healthCheckPath": "/health"
}

services/shop/shop-web/service.json frontend

{
  "appName": "shop-web",
  "appType": "frontend",
  "stack": "shop",
  "port": 3000
}

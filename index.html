Testing and evaluating AI agents

Turn vague agent quality into test cases, graders, baselines and CI guards, without letting a model grade its own homework.

Tool
flisk-sh/flisk
  1. How to write test cases for an AI agentTurn a vague goal like 'the agent should be helpful' into concrete test cases with inputs, expected behaviour and a pass rule you can run on every change.
    5 min
  2. LLM-as-judge pitfalls and how to avoid themUsing a model to grade a model is useful and risky. Learn the common biases, how to write a grading prompt, and how to check the judge against human labels.
    5 min
  3. Deterministic graders for AI agents: check the work, not the wordsGrade agents with code: database state, files, tool-call logs, schemas and regex. Faster, cheaper and more stable than asking another model.
    5 min
  4. Build a golden dataset for agent evals from your logsCollect real agent conversations, remove personal data, label the outcome and freeze a versioned test set that you can run on every change.
    5 min
  5. How to run agent regression tests in GitHub ActionsRun a fast eval suite on every pull request, cache what you can, keep API costs bounded, and fail the build when the score drops below your baseline.
    5 min
  6. How to test agent tool calls and trajectoriesRecord every tool call, then assert on which tools ran, in what order, with what arguments, and how many steps it took. Catch wrong paths that still produce a fine answer.
    5 min
  7. Why agent evals are flaky and how to fix itThe same agent passes a case today and fails tomorrow. Find the sources of noise, repeat runs, set a tolerance from data and stop chasing random failures.
    5 min
  8. Mocking the LLM and tool calls in agent unit testsTest the code around your agent without calling a model: scripted responses, fake tools, recorded replies and a clear line between unit tests and evals.
    5 min
  9. Eval baselines and score ratchets for AI agentsStore a baseline score, fail the build when it drops, and raise the bar when it improves. A ratchet keeps agent quality from slowly getting worse.
    5 min
  10. How to monitor AI agent quality in productionOffline evals miss real-world drift. Track task success, tool errors, retries, cost and user signals, and feed failures back into your test set.
    5 min

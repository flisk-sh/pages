  2. How to cross-compile a Rust service for a Linux containerRust needs a linker for the target, so unlike Go it is not two environment variables. There are three honest routes, and one is a plain Docker build.

  3. How to debug a Go service with Delve while it runs locallyA print statement gets you far, but a breakpoint in a handler is quicker once the bug depends on state. Delve is the Go debugger, and it needs a binary that still has its debug data.
    4 min
  4. How to debug a Rust service with LLDB and VS CodeThe Rust compiler catches a lot before you run anything. For the bugs that remain, a debugger and good logs cover most of what you need.
    3 min
  5. Database migrations for Go and Rust: goose and sqlx locallyGo and Rust each have a good migration tool. The part that goes wrong is when the migrations run, and who runs them.
    4 min
  6. Go API and Vite frontend locally: proxy instead of CORSThe browser calls the API from one origin and the API answers on another. A dev proxy makes the two look like one, so you can leave CORS rules for the day you deploy.
    3 min
  7. Go workspaces (go.work) for a repo with several servicesOne module per service keeps builds small. A workspace file lets those modules see each other's local code while you edit, with nothing to undo before you commit.
    4 min
  8. Air vs reflex vs watchexec: reload a Go app on saveGo has no built-in watcher. Three small tools fill the gap, and they differ in one detail that decides whether your API is down while it compiles.
    4 min

    3 min

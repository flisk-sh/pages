  1. What is prompt injection and how do you defend against it?Prompt injection tricks a model into following instructions that came from data instead of from you. You cannot fully prevent it, so limit what a fooled model can do.
    5 min
  2. Indirect prompt injection: attacks hidden in pages and tool resultsWhen an agent reads a web page, email or issue, the author of that content can speak to your model. Here is how to design so that this does not hurt you.
    5 min
  3. How to keep API keys and secrets away from LLM agentsA model that can see a secret can be tricked into leaking it. Keep keys in your code and your tools, not in prompts, files or tool output the model reads.
    5 min
  4. How to give an AI agent least-privilege tool permissionsDecide what the agent may do before it runs, not after it surprises you. Narrow tools, scoped credentials and allowlists keep a confused agent from doing damage.
    5 min
  5. How to validate LLM output before your app acts on itTreat model output like user input: parse it, check it against a schema, then check it against your rules. Never pass it straight to a shell, a query or a browser.
    5 min
  6. How to safely run code that an LLM wroteModel-written code can delete files, read secrets and call the network. Run it in a throwaway container or microVM with no secrets and limited network.
    5 min
  7. How to secure an MCP server and the tools it exposesAn MCP server hands a model real capabilities. Authenticate callers, scope every tool, treat tool text as untrusted and review third-party servers before you connect them.
    5 min
  8. How to add human approval to risky AI agent actionsLet the agent propose, let a person confirm. Mark which actions need approval, show exactly what will happen, and make the approval hard to bypass.
    4 min
  9. How to build an audit log for AI agent actionsWhen an agent does something wrong you need to know who asked, what it saw and what it did. Log tool calls and decisions in an append-only record.
    4 min
  10. AI app security checklist before you launchA short checklist covering secrets, permissions, untrusted input, output handling, sandboxing, approvals, logging and automated checks in CI.
    5 min

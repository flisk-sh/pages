robots.txt for AI crawlers: GPTBot, ClaudeBot, PerplexityBot

Which AI user agents exist, how to allow or block each in robots.txt, and the difference between training bots and bots that fetch pages for answers.

Control AI crawlers with one User-agent block per bot in robots.txt. To be cited in AI answers, allow the search and user-triggered bots. To keep content out of model training, block the training bots. Check each vendor's documentation for the current list of names.

Know the three kinds of bot

  • Training crawlers collect pages to train models. Examples are GPTBot (OpenAI) and ClaudeBot (Anthropic).
  • Search crawlers index pages so a product can show them in answers. Examples are OAI-SearchBot (OpenAI) and PerplexityBot.
  • User-triggered fetchers load a page when a person asks the assistant about it. Examples are ChatGPT-User and Perplexity-User.

Google uses Googlebot for search and a separate control token, Google-Extended, to let sites opt out of some AI uses. Vendors add and rename bots, so confirm names on their official pages before you rely on them.

Allow everything (the simple default)

User-agent: *
Allow: /

Sitemap: https://example.com/sitemap.xml

If you have no Disallow rules for these bots, they can crawl. Many sites need no change here. The usual problem is a rule you forgot about.

Allow answers, block training

User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: ChatGPT-User
Allow: /

This keeps your content out of training crawls from those bots while leaving search and on-demand fetches open. It is a policy choice, not a technical one. The trade-off is that blocking a training crawler may reduce how well a model knows your product by name.

robots.txt is a request, not a lock

Well-behaved bots follow it. Others do not. For content you truly must protect, use authentication, not robots.txt. Also remember that a firewall or CDN bot rule can block a bot even when robots.txt allows it, so test with curl as in the citation checklist.

Test your file

curl -s https://example.com/robots.txt

Check that it returns 200 and plain text, not an HTML page, and that no earlier group such as User-agent: * with Disallow: / overrides your intent. A bot follows the most specific group that matches its name. Run Citable afterwards to see what AI search can reach.

A review habit

Put robots.txt in version control and review changes like code. A one-line edit can hide a whole site. After each change, fetch the live file and run one curl per bot you care about. Keep a comment above each group saying why it exists, so the next person does not delete a rule or add a blanket block without knowing the reason. Revisit the list of bot names every few months, since vendors add new crawlers and retire old ones.

Questions people ask

Should I block GPTBot?

It depends on your policy. Blocking stops training use by that bot but not search or on-demand fetches, which use other names.

Will blocking AI bots hurt my Google ranking?

Blocking AI-specific bots does not affect Googlebot. Do not block Googlebot itself unless you want to leave Google search.

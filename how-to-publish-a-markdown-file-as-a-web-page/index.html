How to publish a Markdown file as a web page

Turn a README or notes file into a shareable page: a one-command publisher, GitHub's own rendering, or a small build step that converts Markdown to HTML.

The quickest route is a publisher that accepts Markdown directly, such as npx -y @flisk-sh/pages publish notes.md --wait. If you prefer to own the output, convert it to HTML with a tool like pandoc and host the file anywhere.

Publish the file as is

Pages can publish an index.md or a folder with an HTML page to a free public link. It is public, so it suits write-ups, reports and agent output, not private notes.

npx -y @flisk-sh/pages publish notes.md --wait

Convert it yourself with pandoc

Pandoc turns Markdown into a complete HTML page. Install it with your package manager first.

pandoc notes.md -s --metadata title="My notes" -o index.html

The -s flag makes a full document instead of a fragment. Add --css style.css to style it. The result is a normal static page, so any of the hosts in this comparison will serve it.

Let GitHub render it

A Markdown file in a repository already renders nicely at its GitHub URL. That is fine for a README, but it carries GitHub's chrome, and a private repo stays private. For a clean standalone page, publish HTML.

Write Markdown that converts well

  • Start with one # heading. It becomes the page title and the main heading.
  • Use fenced code blocks with a language tag, such as ```bash.
  • Use relative paths for images, and publish the image files too.
  • Keep tables simple. Wide tables overflow on phones.

Add a table of contents and metadata

Long documents need navigation. Pandoc can generate a contents list and read metadata from a YAML block at the top of the file.

---
title: Release notes
description: What changed in this release.
---
pandoc notes.md -s --toc --toc-depth=2 --standalone -o index.html

The title becomes the page title, and a description helps when the link is shared. Read the output once in a browser, since generated HTML can still contain raw text you did not intend to show.

If you generate the Markdown with an AI agent, ask it to use plain headings and avoid HTML inside the file. Pure Markdown converts the same way in every tool, so you can switch publishers later without cleanup. Reread the converted page once, because small issues like unclosed code fences turn a whole section into one grey block.

Check before sharing

Open the result on your phone, check that every link works, and read the page for anything private. The pre-publish checklist covers titles, descriptions and link checks.

Questions people ask

Can I publish Markdown without converting it?

Some services render Markdown for you. Others need HTML. A converter like pandoc works everywhere.

Will images in my Markdown appear?

Only if the image files are published too and the paths are relative to the page. Upload the folder, not just the Markdown file.

Try it

Put one page online in a minute.

Pages publishes an HTML or Markdown file to a free public link. It is public, so do not use it for anything private.

npx -y @flisk-sh/pages publish page.html --wait

# Ship a launch in a week

How we planned Pages for Product Hunt: score the ideas, cut the scope, ship the smallest thing that is real.

> [!TIP]
> Score ideas 1 to 10 on Impact, Confidence and Ease. ICE is the average. Build the top one, not the most fun one.

## The scores

| Idea | Impact | Confidence | Ease | ICE |
| --- | :-: | :-: | :-: | :-: |
| Publish an agent's page to a public link, as a git branch | 7 | 6 | 7 | **6.7** |
| A straight clone of an agent workspace, static and public | 6 | 5 | 7 | 6.0 |
| A curated gallery of explainers | 5 | 4 | 8 | 5.7 |

## What we left out

- Private spaces, teams, sign-in. Everything is public, so there is nothing to secure but the page itself.
- A database. Every space is a branch; every version is a commit.
- An API with keys. Publishing is a pull request from your own fork.

## The week

1. **Days 1–2**: the check, the publish workflow, the static build.
2. **Days 3–4**: skills for the agent, with evals.
3. **Day 5**: seed real spaces like this one.
4. **Day 6**: record the gallery from the live site.
5. **Day 7**: launch at 00:01 Pacific, answer every comment.

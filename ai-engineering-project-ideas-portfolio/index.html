10 AI engineering project ideas that teach real skills

Project ideas that teach something specific, with a clear finish line and a way to measure success. Pick one, scope it to two weeks, and ship it.

The best learning projects have a user, a measurable goal and a small scope. Pick one idea from this list, define what "works" means before you start, and finish it in two weeks.

Ideas that teach retrieval and structure

  1. Docs question answering for one open-source project. Teaches chunking, embeddings and citations.
  2. Receipt or invoice extractor. Photo or text in, validated JSON out. Teaches schemas and error handling.
  3. Meeting notes to action items. Teaches prompts and output checks, with examples you can compare by hand.

Ideas that teach agents and tools

  1. Repo triage agent. Reads new GitHub issues, adds a label and a first-reply draft. Teaches tools and permissions.
  2. Daily briefing agent. Pulls from three sources and sends one summary. Teaches scheduling and failure handling.
  3. A small MCP server that exposes a real data source. See build an MCP server.

Ideas that teach evaluation and cost

  1. A benchmark of your own tasks. Twenty real prompts, a script that scores answers, and a comparison of two models. Teaches evals. See learn evals first.
  2. A cost cutter. Take an existing prompt, add caching and routing to a smaller model, and report the saving. See cutting LLM cost and latency.
  3. A code review helper for your own pull requests that is checked against real bugs from your history.
  4. A site checker that tests whether AI search can read a page. See getting found by AI search.

Scope each one

Write three lines before you code: who uses it, what a good result looks like, and how you will check it. Then cut the scope in half. A finished small project beats a half-finished large one every time. Add a README with a screenshot or a short run log, the commands to run it, and the numbers from your check.

Keep the dependency list short and pin versions, so the project still runs six months later when a reviewer opens it. Add one test, even a tiny one, and a note on what you would do with another week. Finishing a project means someone else can run it without asking you anything.

Make it show up

Publish the result. A public repo with a clear README, and a page that explains what you learned, is worth more than a private folder of experiments. See how to build a portfolio that gets interviews. For ideas that could turn into a paid product, see finding a first customer.

Questions people ask

Should I build something original?

Not at first. Rebuilding a known project teaches the skills. Originality comes from adding your own data, users or constraint.

How long should a learning project take?

One to two weeks of part-time work. If it is longer, scope it down.
